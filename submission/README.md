# Submission materials

This public repository contains the project source code, model artifacts and data, tests, and setup guides.

The university report files and LaTeX source ZIP remain in the local `submission/` folder and are excluded from GitHub. Use this repository URL for the **Code: GitHub link** form field, and upload the local LaTeX ZIP separately to the **Report LaTeX Zip file** field.

For installation and demo steps, see [the setup guide](../FRIEND_SETUP_AND_REPORT_GUIDE.md).
